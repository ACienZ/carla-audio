## 声学计算与假设

参数集中在脚本顶部，含逐项中文注释。默认使用 520/760 Hz 交替的正弦波警笛，每个音持续 0.55 秒，声源振幅为 0.75，声速为 343 米/秒，参考距离为 10 米。

将原始时间戳减去首条时间戳，作为相对仿真时间。模型假定麦克风静止、声源沿直线接近、空气静止、运动速度低于声速且距离保持为正。Actor 原点距离作为传播距离近似；不是车顶警笛到真实麦克风的精确路径。

设发声时刻为 `u`，接收时刻为 `t`：

```text
t = u + distance(u) / 343
```

测量点间的距离按时间线性插值，因此各段的到达时间也是线性的。反插值求得每个接收采样点对应的发声时间，再根据发声时间计算波形。变化的传播时间自然产生多普勒，不再叠加一次频率修正。恒定距离只造成固定时移，不改变频率。

录制前警笛已持续鸣响；负时间继续相同的警笛周期，切换频率时相位连续。为生成开头收到的声音，按前两条测量的距离变化率向前外推约 88 毫秒轨迹。这是短暂历史的边界假设，不是 sensor 测得的历史位置。只设置“警笛已响”还不足以得到这段运动历史，因此单独记录此假设。

对每个采样点，按其发声时刻的传播距离计算振幅：

```text
gain = 10 / max(传播距离, 10)
audio = 0.75 × gain × siren(发声时间)
```

更远时振幅按距离倒数衰减，10 米以内增益保持 1。不进行逐帧或整段音量归一化。接收时刻声源已更近，但当前声音来自较早、更远的位置，所以本次接收增益约从 0.33139 增至 0.99416，结尾略小于 1 属于传播模型的预期结果。

本轮不模拟反射、遮挡、空气吸收、背景噪声、真实警笛素材、麦克风频响或立体声。不把双音正弦波当作真实警笛的音色验证。任意双方运动需要位置与运动信息，不能直接复用当前仅有距离的模型。

脚本按当前完整输入直接计算，不增加数据修复、重试或异常恢复。输入应有至少两个严格递增时间点、正距离，且到达时间单调；畸形输入不在本轮支持范围。文件写入不是原子操作，中断可能留下不完整派生结果，重新正常运行后再使用。片段起止直接截取，不加淡入淡出，播放边缘可能有截断声，不据此判断帧间相位不连续。

## 帧边界与读取

完整波形覆盖接收时间 `[0, 最后相对时间)`。201 个测量点围出 200 个区间，最后一点只提供终点，不额外生成最后一帧音频。每个边界均从同一时间原点计算：

```text
sample_index = round(relative_timestamp × sample_rate)
```

相邻区间共用边界，采用左闭右开切片。索引顶层为 `sample_rate`、`total_samples`、`intervals`；本次第一个区间如下：

```json
{
  "frame": 1658,
  "next_frame": 1659,
  "start_sample": 0,
  "end_sample": 2400
}
```

以下示例在本目录运行，读取完整 WAV 并取第一个区间，不另存小 WAV：

```python
import json
import wave
from pathlib import Path

import numpy as np

output = Path("data/derived")
index = json.loads(
    (output / "20261019_133736_286515_frame_index.json").read_text(encoding="utf-8")
)
with wave.open(str(output / "20261019_133736_286515.wav"), "rb") as wav_file:
    audio = np.frombuffer(wav_file.readframes(wav_file.getnframes()), dtype="<i2")

interval = index["intervals"][0]
frame_audio = audio[interval["start_sample"]:interval["end_sample"]]
print(interval["frame"], frame_audio.shape)
```

索引表示从某测量时刻到下一测量时刻听见的声音，不是该时刻才发出的声音。面向当前帧的模型输入应截取截至当前时刻的历史窗口，避免把之后的音频作为当前已知信息。后续正式数据集沿用完整波形后取时间片段的方式，具体模型窗口另行确定。
